# ForGo 3.4.0 — Game Hub

ForGo — универсальный игровой оптимизатор для Windows. Он объединяет библиотеку поддерживаемых игр, обратимые системные настройки и инструменты обслуживания ПК в одном приложении.

> **Статус:** проект в разработке. Перед использованием системных твиков внимательно читайте их описание. Прирост FPS или снижение задержки не гарантируются.

## Возможности

- Библиотека игр и запуск через официальные клиенты.
- Настройки Windows с предусмотренным возвратом исходных значений.
- Временное управление приоритетом процесса выбранной игры.
- Мониторинг загрузки CPU и использования памяти.
- Инструменты для временных файлов, DNS-кэша и просмотра процессов.
- Интерфейс на PySide6 с темой Liquid Glass.

## Требования для сборки

- Windows 10 или Windows 11, 64-bit
- Python 3.11 или 3.12 x64
- Интернет для установки зависимостей при первой сборке

## Сборка EXE

1. Скачайте исходники репозитория или нажмите **Code → Download ZIP**.
2. Распакуйте проект в короткий путь, например `C:\ForGo`.
3. Установите Python 3.11/3.12 x64, включив Python Launcher и добавление Python в PATH.
4. Запустите `build.bat`.
5. При успешной сборке приложение появится в `dist\ForGo.exe`.

Зависимости перечислены в `requirements.txt`. Сам EXE и build output намеренно не хранятся в исходниках: готовую сборку можно прикреплять к GitHub Releases.

## Безопасность и ограничения

- ForGo предназначен для настройки Windows и запуска игр через официальные клиенты.
- Не следует отключать защиту Windows, античиты, брандмауэр или обновления ради сомнительных обещаний FPS.
- Системные настройки могут вести себя по-разному в разных версиях Windows. Применяйте только понятные вам твики и проверяйте доступность восстановления.
- Программа не гарантирует увеличение FPS, уменьшение пинга или задержки.

## Распространение

Для распространения готового установщика или EXE используйте **GitHub Releases**, а исходный код храните в репозитории. Не добавляйте `dist/`, `build/`, `.venv/` или установщик в обычный коммит.
